# 작업 목록: 습득물 등록 및 검색

상태: 완료 (TASK-1~TASK-7)

## 착수 승인
- 계획과 작업 목록은 사용자가 승인했다.
- 기술 스택과 장소 검색 정규화 규칙은 결정되어 계획 및 명세에 반영했다.

## 작업
- [x] TASK-1 (REQ-1~REQ-14, AC-1~AC-10): 기술 스택과 데이터/사진 저장소를 결정하고 실행·테스트 가능한 앱 기반을 구성한다.
  - 검증: 새 환경에서 설치·실행이 가능하고 기본 검사가 통과한다.
- [x] TASK-2 (REQ-1, REQ-6, REQ-14; AC-1, AC-10): 습득물 데이터 모델과 등록·저장 흐름을 구현한다. 제목, 카테고리, 장소, 특징, 날짜를 저장하고 미래 날짜 입력을 거부한다.
  - 검증: 필수 필드 등록, 저장 후 조회, 날짜 기본값·과거 날짜·미래 날짜 테스트.
- [x] TASK-3 (REQ-4, REQ-5, REQ-8; AC-3, AC-5): 6개 고정 카테고리와 대표 예시를 제공하고 등록 및 검색 필터에 연결한다.
  - 검증: 카테고리 목록과 예시 표시, 선택한 카테고리만 반환되는 테스트.
- [x] TASK-4 (REQ-2, REQ-3, REQ-12; AC-2, AC-8): 선택 사진 업로드, 형식·장수·크기 검증, 사진 없는 결과의 플레이스홀더를 구현한다.
  - 검증: 사진 없음, JPG/PNG/WEBP, 3장 및 5 MB 경계, 형식·용량 초과 테스트.
- [x] TASK-5 (REQ-7, REQ-9, REQ-10, REQ-11; AC-4, AC-6, AC-7): 장소 부분 일치와 제목·특징·장소 대상의 키워드 검색, 필터 조합을 구현한다.
  - 검증: 장소 예시, 여러 단어 AND, 검색 대상 필드 간 OR, 장소·카테고리·키워드 동시 적용 테스트.
- [x] TASK-6 (REQ-12, REQ-13; AC-8, AC-9): 검색 결과 항목과 빈 결과 상태를 구현한다.
  - 검증: 결과의 식별 정보 및 사진 유무별 표시, 결과 없음 상태 테스트.
- [x] TASK-7 (REQ-1~REQ-14; AC-1~AC-10): 등록부터 검색까지 통합 흐름을 검증하고 회귀 검사를 실행한다.
  - 검증: 모든 인수 기준 테스트와 프로젝트 전체 검사 통과.
