# 기능 명세: 습득물 등록 및 검색

상태: 초안 (사용자 검토 대기)

## 문제
분실물을 찾는 사람은 습득물 정보를 한곳에서 검색할 수 없고, 습득자는 물건의 정보를 일관되게 공유하기 어렵다.

## 목표
- 습득자가 사진, 카테고리, 습득 장소, 특징, 습득 날짜를 포함해 습득물을 등록할 수 있다.
- 사용자가 장소, 카테고리, 키워드로 등록된 습득물을 검색하고 결과를 확인할 수 있다.

## 제외 범위
- 분실물 등록 및 습득물과의 자동 매칭
- 사용자 계정, 소유권 확인, 채팅 또는 연락 기능
- 지도 기반 장소 선택 및 위치 정보 자동 수집
- 등록 정보 수정, 삭제, 신고 및 관리자 기능

## 사용자 시나리오
- 습득자는 물건을 발견한 뒤 사진과 습득 정보를 등록해 분실자가 찾을 수 있게 한다.
- 분실자는 기억하는 장소나 물건 종류를 선택하고 특징을 검색해 해당 습득물이 등록되어 있는지 확인한다.

## 요구사항
- REQ-1: 습득물 등록은 사진, 카테고리, 습득 장소, 특징, 습득 날짜를 입력할 수 있어야 한다.
- REQ-2: 등록된 습득물은 검색 결과에 반영되어야 한다.
- REQ-3: 사용자는 습득 장소를 기준으로 결과를 필터링할 수 있어야 한다.
- REQ-4: 사용자는 카테고리를 기준으로 결과를 필터링할 수 있어야 한다.
- REQ-5: 사용자는 키워드로 습득물의 특징을 검색할 수 있어야 한다.
- REQ-6: 장소, 카테고리, 키워드 조건은 함께 적용할 수 있어야 한다.
- REQ-7: 검색 결과에는 물건을 식별하는 데 필요한 사진(등록된 경우), 카테고리, 습득 장소, 특징, 습득 날짜가 표시되어야 한다.
- REQ-8: 검색 조건에 맞는 결과가 없으면 결과가 없음을 알 수 있어야 한다.

## 인수 기준
- AC-1 (REQ-1, REQ-2): 유효한 습득 정보를 입력해 등록하면, 등록이 완료되고 해당 정보가 검색 결과에서 확인된다.
- AC-2 (REQ-1): 습득물 등록 화면에서 사진, 카테고리, 습득 장소, 특징, 습득 날짜를 입력할 수 있다.
- AC-3 (REQ-3): 습득 장소 필터를 적용하면 해당 장소와 일치하는 습득물만 표시된다.
- AC-4 (REQ-4): 카테고리 필터를 적용하면 해당 카테고리의 습득물만 표시된다.
- AC-5 (REQ-5): 특징의 일부와 일치하는 키워드를 검색하면 해당 특징을 포함하는 습득물이 표시된다.
- AC-6 (REQ-6): 장소, 카테고리, 키워드를 함께 지정하면 모든 조건에 맞는 결과만 표시된다.
- AC-7 (REQ-7): 검색 결과의 각 항목에서 사진(등록된 경우), 카테고리, 습득 장소, 특징, 습득 날짜를 확인할 수 있다.
- AC-8 (REQ-8): 검색 결과가 없을 때 빈 결과 상태가 표시된다.

## 미결 사항
- 사진은 등록 필수 항목인가, 선택 항목인가?
- 카테고리는 고정된 목록으로 제공할 것인가? 목록을 제공한다면 어떤 항목을 포함하는가?
- 습득 장소와 특징은 자유 입력으로 할 것인가? 장소 필터는 정확히 일치하는 값만 대상으로 하는가?
- 키워드 검색은 대소문자/공백을 무시할 것인가, 여러 검색어를 어떻게 처리할 것인가?
- 사진 파일 형식, 크기 제한 및 업로드 개수는 어떻게 할 것인가?
- 날짜 입력은 달력 선택만 제공할 것인가? 미래 날짜 입력을 허용할 것인가?
